# Aimili Gateway

Aimili Gateway 是 AimiliVPN 与 3x-ui 的轻量统一控制台项目。统一控制台负责日常管理、统一登录和跨服务编排；AimiliVPN、3x-ui 与 Xray 继续作为独立服务运行、更新和排障。

## 当前阶段

项目目前处于架构设计审核阶段，只包含设计文档，不包含可执行代码、部署脚本或生产配置。正式设计再次获得批准后，才会编写实施计划并开始开发。

## 重要文件

- `docs/superpowers/specs/2026-08-24-unified-console-design.md`：统一控制台 V1 的需求、架构、认证、安全、适配器、兼容性和验收设计。

## 使用方法

请先阅读并审核上述设计文档。当前阶段没有构建或运行命令。

## 验证

设计文档提交前应完成以下检查：

1. 不含未决占位符或未完成标记。
2. 统一控制台登录、3x-ui 专家模式登录和真正 SSO 的边界没有混淆。
3. V1 明确限制为个人单管理员使用，不包含多租户和复杂 RBAC。
4. 不输出或保存到版本库中的密码、Cookie、令牌、私钥、UUID、随机后台路径或完整订阅链接。
5. 未经明确授权，不连接或修改生产 VPS。

## 依赖与限制

- 设计基线为 Go 控制台后端、Vue 前端和 SQLite；具体依赖版本将在设计批准后的实施计划中锁定。
- V1 不重写 AimiliVPN、3x-ui 或 Xray 核心，不把它们合并成单个进程。
- 原版 3x-ui 后台保留为专家模式，并继续使用 3x-ui 自身认证。
- 当前仓库尚未发布到远端。
