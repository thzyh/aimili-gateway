## 下一项必要证据与修复决策

原 Edge 页再次失败时，保留当前节点和页面，在 Console 与 Network 启用 Preserve log，取得以下脱敏信息：

1. Turnstile 六位错误码以及发生时间；不要只记录通用“验证失败”文字。
2. `ping0.cc`、`challenges.cloudflare.com` 核心验证请求的状态、耗时和浏览器网络错误码；不要输出 Cookie、验证 token、完整验证 URL 或请求体。
3. 若是连接/TLS 超时，同步捕获客户端与 tun120 元数据，按当时目标 IP、连接和时间定位第一处阻塞。
4. 若是验证拒绝，保持同一出口，在用户明确选择的原浏览器环境做单变量对照。已安装扩展、共享 IP 或自行恢复都不能单独作为原因；不能把浏览器测试环境改变误算为服务器修复。

Cloudflare 的错误码区分超时、iframe 载入失败与验证拒绝；个别 PAT 401 和随机诊断子域名 DNS 失败也可能是正常流程，不能看见任意红色请求就归因。参考[客户端错误码](https://developers.cloudflare.com/turnstile/troubleshooting/client-side-errors/error-codes/)、[验证故障排查](https://developers.cloudflare.com/cloudflare-challenges/troubleshooting/challenge-solve-issues/)和[浏览器支持范围](https://developers.cloudflare.com/cloudflare-challenges/reference/supported-browsers/)。
