# `ny` VPS V1-D 高级设置与统一凭据验收记录

## 验收目标

- 删除近期重新认证业务门槛，同时保留登录会话、同源、CSRF、幂等键和 `no-store` 防护。
- SOCKS5H 来源限制可显式开启或关闭，并对全部在线受管组原子应用或回滚。
- 提供 Gateway 原生 AimiliVPN 与 3x-ui 高级维护页面。
- Gateway、AimiliVPN 与 3x-ui 使用统一用户名和密码；Gateway 服务端可为两个原后台签发独立会话并跳转。
- 明确该机制是“统一凭据＋服务端自动代登录”，不是覆盖全部页面的真正 SSO。
- 512 MiB VPS 继续保持 `maxProxyGroups=1`，不扩大常驻代理容量。

本记录不得包含密码、Cookie、控制令牌、TOTP 秘钥、UUID、私钥、随机后台路径或完整代理、订阅地址。

## 固定范围与版本

- Gateway 功能分支：`feature/v1d-unified-credentials`。
- AimiliVPN 功能分支：`feature/v1d-managed-admin`。
- 3x-ui、Xray 与 AimiliVPN 核心继续独立运行；Gateway 只管理 `agw-` 命名空间。
- 3x-ui 更新只通过已验证的回环 HTTP 契约完成，不直接读写 `x-ui.db`。
- 自动代登录失败时必须保留原后台手动登录回退，且不得影响现有代理数据面。
