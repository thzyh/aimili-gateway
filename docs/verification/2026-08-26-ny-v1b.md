# ny VPS 国家代理 V1-B 验收记录

## 验收范围

- Gateway 单管理员登录、重新认证和国家目录读取。
- 一个国家与出口类型对应一个稳定代理组，同时创建 VLESS Reality 和 mixed/SOCKS5H 入站。
- 两种协议均通过 AimiliVPN 槽位出站，且使用代理端 DNS。
- mixed 来源 CIDR 白名单和未授权来源拒绝。
- 检测不更换出口；换 IP 保持国家、类型、端口和入口身份，并在换后重新验证两种协议。
- AimiliVPN、3x-ui、Xray、Caddy 和 Gateway 继续作为独立服务运行。

## 本轮修复

- Gateway `7d824c1`：Reality 不再依赖不稳定的远端伪装目标，改用 VPS 本机 HTTPS 服务作为受控目标；公网域名继续作为允许的 SNI。适配器拒绝任意 Reality 目标。
- AimiliVPN `33eda73`：受管换 IP 在后台供给器短暂持锁时等待，不再瞬时耗尽重试次数。
- AimiliVPN `05556f8`：每槽位明确的住宅/机房类型优先于旧 UI 的全局“仅住宅”开关，修复机房槽位换 IP 和重启恢复时的互斥过滤。

## 账户边界

- Gateway 普通页面和将来由 Gateway 原生实现的高级设置使用 Gateway 账户。
- 原版 3x-ui 专家模式仍使用 3x-ui 自己的登录，不是真正单点登录。
- AimiliVPN 与 3x-ui 的服务自动化凭据独立保存，不等同于用户账户。
- 正式使用前在 VPS 执行 `sudo aimili-gateway-account`，可查看用户名、设置随机或自定义新密码、启用或关闭 TOTP，并撤销旧会话。命令不会显示当前密码，因为系统只保存密码哈希。
